# 🌌 TikTok Live Galaxy Gift Overlay

A self-contained, high-performance animated overlay for the iconic **Galaxy Gift**.

## 🚀 Live Demo
- **GitHub Pages**: [https://notgoku151.github.io/galaxy-gift/](https://notgoku151.github.io/galaxy-gift/)

## 🎨 Features
- Auto-starts and loops continuously.
- Transparent canvas overlay suitable for OBS Studio, TikTok Live Studio, and browser sources.
- Procedural logarithmic spiral arms, central bulge, cosmic dust bands, comets, and shockwave starbursts.
- Synthesized Web Audio effects (no external audio files needed).
- Fully responsive on mobile, desktop, and live streaming screens.

## 🎛️ Query Parameters (Optional)
- `?overlay=1` - Hides UI controls and runs directly as a broadcast overlay.
- `?name=YourName` - Custom sender name.
- `?creator=CreatorName` - Target creator handle.
- `?message=Custom+Message` - Custom gift message.
- `?sound=0` - Start with sound muted.
